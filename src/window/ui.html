Globlin

General

Run at startup Starts in the tray when you sign in, without opening this window.
Monochrome tray icon Draws the goblin in one colour that matches the system icons beside it. A dot means updates are waiting; an exclamation mark means something went wrong.
Approve npm install scripts automatically Skips the approval dialog. Any dependency’s install scripts then run without you seeing them.
Update everything when Globlin starts After the first check, runs Update all once. Ignored packages are left alone.
One administrator prompt for all choco updates Runs every choco update in a batch under a single Windows prompt. Their rows finish together when the last one is done.
One administrator prompt for all winget updates Runs every winget update in a batch as administrator under a single Windows prompt. Their rows finish together when the last one is done. A few installers refuse to run as administrator and then fail.
Update Globlin automatically Installs new Globlin releases in the background, verified against their signature.
Globlin restarts into the new version when the update finishes.
